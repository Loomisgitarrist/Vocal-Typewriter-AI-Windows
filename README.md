## 🚀 STEP-BY-STEP GUIDE

### Step 1: Install Node.js (if you don't have it)

**Option A: Download from website**
1. Go to https://nodejs.org
2. Download the LTS version
3. Install it (just click Next through the installer)

**Option B: Install via terminal**

*macOS (using Homebrew):*
```bash
# Install Homebrew first (if you don't have it):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Then install Node.js:
brew install node
```

*Windows (using winget - built into Windows 10/11):*
```cmd
winget install OpenJS.NodeJS.LTS
```


### Step 1b: Install Rust (Required for Tauri)

**On Mac:**
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

**On Windows:**
Download and run: https://win.rustup.rs/

> **Note:** The build script will automatically install **bun** if your project requires it (many Tauri projects use bun as their build tool).


### Step 2: Copy Build Scripts to Your Project

1. Extract the downloaded ZIP file
2. Copy ALL the script files into your project folder (where package.json is located)

Your project folder should now look like:
```
your-project/
├── package.json        # Your existing file
├── main.js             # Your existing file (or similar)
├── build.sh            # ← You just added this
├── build-macos.sh      # ← You just added this (if building for Mac)
├── build-windows.bat   # ← You just added this (if building for Windows)
└── README.md           # This file (optional to copy)
```

### Step 3: Open Terminal and Go to Your Project Folder

**On Mac:**
1. Open **Terminal** (press Cmd+Space, type "Terminal", press Enter)
2. Type `cd ` (with a space after it) - don't press Enter yet!
3. Drag your project folder from Finder into the Terminal window
4. Press Enter

**On Windows:**
1. Open your project folder in File Explorer
2. Click in the address bar at the top
3. Type `cmd` and press Enter - this opens Command Prompt in that folder!

### Step 4: Run the Build Script

**On Mac (creates .dmg file):**
```bash
bash build-macos.sh
```

**On Windows (creates .exe file):**
Double-click `build-windows.bat` OR in Command Prompt type:
```cmd
build-windows.bat
```

**Universal script (auto-detects your OS):**
```bash
bash build.sh
```

## ❓ Troubleshooting

### "command not found: npm"
Node.js isn't installed or not in PATH. Restart your terminal after installing Node.js.

### Build fails with dependency errors
1. Delete the `node_modules` folder in your project
2. Run `npm install`
3. Try the build script again

### "App is damaged" on macOS
Your app isn't code signed. For testing: Right-click the app → Open → Open.

### SmartScreen warning on Windows
Your app isn't code signed. Click "More info" → "Run anyway" to test.
